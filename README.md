# SOC Analyst Portfolio

Здесь собраны мои практические работы по анализу инцидентов и мониторингу безопасности.

## Что внутри:
* **LetsDefend:** Разбор алертов (True/False Positive).
* **CyberDefenders:** Анализ фишинговых писем.
* **TryHackMe:** Расследования инцидентов (SIEM/EDR).

## Структура:
* `/Investigations/` — разборы алертов и write-ups.
* `/IncidentResponse/` — отчеты по расследованиям.
* `/SIEM/` — запросы и скриншоты дашбордов.
